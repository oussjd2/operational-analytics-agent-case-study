# Visual sources and scope

The workflow and model-evolution SVGs adapt the diagrams in the portfolio's `src/components/agent-diagrams.tsx`. The public workflow is described in `src/content/projects.ts` under `ai-assistant-for-operational-analytics`.

These are conceptual diagrams of the implemented workflow. They are not application screenshots, production transcripts, evaluation evidence, or exact runtime traces. No conversation screenshot has been invented to fill a visual gap.

The SVGs are editable text assets. Mermaid equivalents are in [diagrams.md](diagrams.md). Keep both representations aligned when updating the public architecture narrative.
